# 🎓 Udemy Clone (Basic HTML & CSS)

This is a static **Udemy clone website** built using only HTMLand CSS.  
It demonstrates the layout, design, and responsiveness of an online learning platform homepage similar to Udemy.

---

## 🚀 Features
- Clean and responsive design  
- Navigation bar with logo and links  
- Hero section with a call-to-action  
- Course categories layout  
- Course cards with titles, images, and descriptions  
- Footer section with links  

---

## 🛠️ Technologies Used
- HTML5– for structure  
- CSS3 – for styling and layout  
  - Flexbox  
  - CSS Grid  
  - Media Queries
